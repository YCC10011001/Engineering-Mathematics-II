Convergence or Divergence?
  • The slope of g1(x) is less than the slope of y = x, which is 1, thus g′1(x) < 1,
    • Convergence.
  • In the upper part, g1(x) is steeper (g′1(x) > 1)
    • Divergence.
  • The slope of g2(x) is less than 1 near the intersection point (x = 2.618, fixed point of g2, solution of f(x) = 0), and both sequences seem to converge.
  • Convergence seems to depend on the fact that in a neighborhood of a solution the curve of
    g(x) is less steep than the straight line y = x,
    • g′(x) < 1 (= slope of y = x) is sufficient for convergence.

Theorem (1)
Convergence of Fixed-Point Iteration
Let x = s be a solution of x = g(x) and suppose that g has a continuous derivative in some interval J containing s. Then if g′(x) ≤ K < 1 in J, the iteration process converges for any x0 in J, and the limit of the sequence {xn} is s.

  • Solving equations f(x) = 0
  • Simple and fast
  • Approximate the graph of f by suitable tangents.
  • Using an approximate value x0 obtained from the graph of f, we let x1 be the point of intersection of the x-axis and the tangent to the curve of f at x0

Example 3 - Square Root
  • Set up a Newton iteration for computing the square root x of a given positive number c and apply it to c = 2.
  • Solution. We have x = c, hence f(x) = x2 − c = 0, f′(x) = 2x, and (3) takes the form
    xn+1 = xn − x2n − c2xn = 12(xn + cxn).
  • For c = 2, choosing x0 = 1, we obtain
    x1 = 1.500000, x2 = 1.416667, x3 = 1.414216, x4 = 1.414214, ...
    x4 is exact to 6D.
Example 4 - Algebraic Equation
  • Apply Newton's method to the equation f(x) = x3 + x − 1 = 0.
  • Solution. From (3), we have
    xn+1 = xn − x3n + xn − 13x2n + 1 = 2x3n + 13x2n + 1.
    Starting from x0 = 1, we obtain
    x1 = 0.750000, x2 = 0.686047, x3 = 0.682340, x4 = 0.682328, ...
    where x4 has the error −1 · 10−6. A comparison with Example 2 shows that the present convergence is much more rapid. This may motivate the concept of the order of an iteration process, to be discussed next.
Order of an Iteration Method. Speed of Convergence
  • The quality of an iteration method may be characterized by the speed of convergence.
  • Let xn+1 = g(xn) define an iteration method, and let xn approximate a solution s of x = g(x).
    • xn = s − εn, where εn is the error of xn.
  • Suppose that g is differentiable a number of times, so that the Taylor formula gives
    (4)xn+1 = g(xn)= g(s) + g′(s)(xn − s) + 12g′′(s)(xn − s)2 + ...= g(s) − g′(s)εn + 12g′′(s)ε2n + ... .
Order of an Iteration Method. Speed of Convergence
  • The exponent of εn in the first nonvanishing term after g(s) is called the order of the iteration process defined by g. The order measures the speed of convergence.
  • To see this, subtract g(s) = s on both sides of (4)
    • Left side: xn+1 − s = −εn+1, where εn+1 is the error of xn+1.
    • Right side: the remaining expression equals approximately its first nonzero term because εn is small in the case of convergence.
Order of an Iteration Method. Speed of Convergence
(5a)εn+1 ≈ +g′(s)εnin the case of first order, (5b)εn+1 ≈ −12g′′(s)ε2nin the case of second order, etc.
  • Thus if εn = 10−k in some step, then for second order,
    εn+1 = c · (10−k)2 = c · 10−2k,
    so that the number of significant digits is about doubled in each step.

  • Solution. We have f(x) = x − 2 sin x = 0. Differentiation gives
    f′′(s)2f′(s) ≈ f′′(x1)2f′(x1) = 2 sin x12(1 − 2 cos x1) ≈ 0.57.
