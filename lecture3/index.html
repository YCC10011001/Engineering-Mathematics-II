Vector Space
Definition
  • In a nonempty set V, there are defined two algebraic operations
    • Vector addition: a + b
    • Scalar multiplication: αa
  • For any two vectors a, b in V, their linear combinations are also elements of V
(1)∀ a, b ∈ V  ⇒  a + b ∈ V (2)∀ a ∈ V  ⇒  αa ∈ V.
Definition (conti.)
  • A vector space V satisfies the following properties related to vector addition
    ∀ a, b, c ∈ V.
(1) Commutativity: a + b = b + a
(2) Associativity: (a + b) + c = a + (b + c)
(3) Additive Identity: Exist a zero vector 0 in V such that a + 0 = a
(4) Additive Inverse: Exist a vector −a ∈ V, such that a + (−a) = 0
Definition (conti.)
  • A vector space V satisfies the following properties related to scalar multiplication
    ∀ a, b ∈ V and scalars α, β:
(5) Distributivity: α(a + b) = αa + αb
(6) Distributivity: (α + β)a = αa + βa
(7) Associativity: α(βa) = (αβ)a
(8) Multiplicative Identity: ∀ a ∈ V, 1a = a.

Basis and Dimension
  • V is a vector space and S is a subset in V, if:
    • The vectors in S are linearly independent
    • span(S) = V
⇒ S is a basis for the vector space V
  • dim(V): Dimension of V
    • The maximum number of linearly independent vectors in V
    • The number of vectors of a basis for V

Rank
  • Definition:
The rank of a matrix Am×n is the maximum number of linearly
independent row vectors of A.
rank(A)= dim(Range(A)) = dim(Col(A)) = dim(Row(A)) = the number of the pivot elements = rank(AT).
Nullity
  • Definition:
The dimension of the null space of Am×n.
nullity(A)= dim(Null(A)) = The number of ci in the solution of the   homogeneous system (Ax = 0) = Number of columns of A − rank(A).
rank(A) + nullity(A) = Number of columns of A
